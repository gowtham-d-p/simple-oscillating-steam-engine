# Simple Oscillating Steam Engine

## Project Overview

This project presents the 3D CAD design and assembly of a simple oscillating steam engine using SolidWorks.

## Working Principle

In an oscillating steam engine, the cylinder pivots around a fixed point as the piston reciprocates. The connecting mechanism transfers piston motion to a crankshaft, producing rotary motion. In a working steam-powered version, cylinder oscillation also helps control steam admission and exhaust through appropriately arranged ports.

## Main Components

- Cylinder
- Piston
- Piston rod
- Crankshaft
- Crank and connecting mechanism
- Flywheel
- Supporting frame and mounting components

*The final component list depends on the actual CAD assembly.*

## Software Used

- SolidWorks — 3D modelling and assembly

## Project Objectives

- Create 3D models of the engine components.
- Assemble the components and understand their relationships.
- Study the conversion of reciprocating motion into rotary motion.
- Understand the operating principle of an oscillating steam engine.
- Prepare engineering drawings and document the design.
